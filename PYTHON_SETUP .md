# Python and Virtual Environment Setup

## Emotion Detection and Learning Support Engine

## Python Requirement

This project requires Python 3.9 or above.

Python can be downloaded from the official Python website.

## Verify Python Installation

Run the following command:

python --version

## Create Virtual Environment

A dedicated Python virtual environment is used for clean dependency management.

Create the virtual environment using:

python -m venv .venv

## Activate Virtual Environment

### Windows

.venv\Scripts\activate

### Linux / macOS

source .venv/bin/activate

## Verify Virtual Environment

After activation, verify the Python version:

python --version

Verify pip installation:

pip --version

## Purpose

Using a virtual environment keeps project dependencies isolated from other Python projects and helps maintain a clean and reproducible development environment.

## Status
